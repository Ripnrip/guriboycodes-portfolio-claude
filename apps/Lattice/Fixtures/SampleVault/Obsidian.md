# Obsidian

The prior art. Markdown files on disk, `[[wikilinks]]`, and a force-directed graph view.

Lattice keeps the file format so both apps can share one vault. See
[[Lattice#design-goal]] — though note that a fenced block never yields links:

```markdown
This [[Not A Link]] and #not-a-tag are inside code.
```
